# 🌸 Draftbook — Cozy & Aesthetic Productivity Suite

> A soft-pink, minimalist productivity app designed for calm, low-pressure task, goal, and habit management. Built with **Rails 8**, **Tailwind CSS**, and **MySQL 8**.

---

## ✨ Features

- 📋 **Tasks Manager**: Track daily to-dos with interactive interactive completion toggles (`💗` / `🤍`).
- 🎯 **Goals & Milestones**: Monitor long-term targets and achievements (`🎉` / `🎯`).
- 💖 **Habits Tracker**: Build daily routines and maintain continuous streak logs.
- 🎨 **Pastel-Pink UI**: Soft, modern, responsive interface powered by Tailwind CSS.
- 🔒 **Secure Authentication**: Built-in Rails 8 authentication with isolated user data (`has_secure_password`).
- ⚡ **Hotwire Turbo**: Fast, seamless UI updates without full page reloads.

---

## 🛠️ Tech Stack

- **Framework**: [Ruby on Rails 8.0](https://rubyonrails.org/)
- **Language**: Ruby 3.x
- **Database**: MySQL 8.0
- **Styling**: Tailwind CSS
- **Frontend Interactivity**: Hotwire (Turbo & Stimulus)
